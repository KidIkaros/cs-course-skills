# CS 6250 Computer Networking - Syllabus

## Course Overview

**Course**: CS 6250 - Computer Networking
**Institution**: Georgia Institute of Technology (Georgia Tech)
**Program**: Online Master of Science in Computer Science (OMSCS)
**Platform**: Udacity (free access)
**Level**: Intermediate
**URL**: https://www.udacity.com/course/computer-networking--ud436

## Course Description

This course covers the fundamentals of computer networking, exploring the layers of network protocols from the physical layer up to the application layer. Students will learn about the design and implementation of modern network protocols, routing algorithms, network security, and wireless networks.

## Learning Objectives

Upon completion, students will be able to:

1. Explain the layered architecture of computer networks (OSI and TCP/IP models)
2. Describe and analyze link-layer protocols including Ethernet and ARP
3. Understand IP addressing, subnetting, and route aggregation
4. Compare and contrast routing algorithms (distance-vector, link-state, path-vector)
5. Analyze TCP reliable delivery, flow control, and congestion control mechanisms
6. Explain DNS hierarchy and name resolution processes
7. Describe HTTP protocol mechanics and web architecture
8. Identify common network security threats and countermeasures
9. Understand wireless networking standards and protocols

## Module Breakdown

### Module 0: Introduction and Overview
- Course logistics and expectations
- Network performance metrics
- Packet switching vs circuit switching
- Layered protocol models

### Module 1: Physical and Link Layer Fundamentals
- Physical transmission and encoding
- Error detection and correction
- MAC protocols and channel allocation
- Ethernet and IEEE 802.3

### Module 2: Link Layer Protocols and Switching
- ARP (Address Resolution Protocol)
- LAN switches and bridging
- VLANs and trunking
- Spanning Tree Protocol

### Module 3: Network Layer - Addressing
- IPv4 address classes and subnetting
- CIDR (Classless Inter-Domain Routing)
- NAT (Network Address Translation)
- IPv6 addressing

### Module 4: Network Layer - Routing
- Forwarding tables and longest prefix match
- Distance-vector routing (RIP)
- Link-state routing (OSPF)
- BGP (Border Gateway Protocol)

### Module 5: Software-Defined Networking
- SDN architecture and principles
- OpenFlow protocol
- Network virtualization
- Cloud networking

### Module 6: Transport Layer - UDP
- UDP header and operation
- Multiplexing and demultiplexing
- UDP checksums
- Use cases for UDP

### Module 7: Transport Layer - TCP
- TCP connection management
- Reliable data transfer
- Flow control (sliding window)
- Congestion control (slow start, AIMD, fast recovery)

### Module 8: Application Layer - DNS
- DNS hierarchy (root, TLD, authoritative)
- DNS record types
- DNS caching and TTL
- DNS security (DNSSEC)

### Module 9: Application Layer - HTTP and Email
- HTTP/1.1, HTTP/2, HTTP/3
- Persistent connections
- SMTP, POP3, IMAP
- Web proxies and caching

### Module 10: Network Security
- Cryptographic foundations
- TLS/SSL protocol
- IPsec and VPNs
- Firewalls and packet filtering
- Intrusion detection systems

### Module 11: Wireless and Mobile Networks
- IEEE 802.11 (Wi-Fi) standards
- CSMA/CA and hidden terminal problem
- Cellular networks (4G, 5G)
- Mobile IP

## Assessment Structure

- Quizzes after each module
- Programming assignments (Python-based)
- Midterm and final examinations
- Optional networking labs with Wireshark

## Prerequisites

- Basic programming skills (Python preferred)
- Understanding of binary and hexadecimal number systems
- Familiarity with client-server concepts
- Basic probability and statistics knowledge

## Recommended Textbooks

- **Computer Networking: A Top-Down Approach** by James Kurose and Keith Ross
- **TCP/IP Illustrated, Volume 1** by W. Richard Stevens
- **Computer Networks** by Andrew Tanenbaum

## Tools and Software

- **Wireshark**: Packet capture and protocol analysis
- **Cisco Packet Tracer**: Network simulation
- **Python**: Scripting for networking assignments
- **Mininet**: SDN network emulation
