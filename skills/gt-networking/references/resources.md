## Textbooks

### Primary
- **Computer Networking: A Top-Down Approach** (8th Edition)
  - Authors: James Kurose, Keith Ross
  - ISBN: 978-0135928608
  - Website: http://www-net.cs.umass.edu/kurose-ross/

### Supplementary
- **TCP/IP Illustrated, Volume 1: The Protocols**
  - Author: W. Richard Stevens
  - ISBN: 978-0321336316
  - Classic reference for TCP/IP implementation details

- **Computer Networks** (5th Edition)
  - Author: Andrew Tanenbaum
  - ISBN: 978-0132126953
  - Comprehensive theoretical foundation

- **Unix Network Programming, Volume 1**
  - Author: W. Richard Stevens
  - ISBN: 978-0131411555
  - Socket programming reference

## Online Resources

### Protocol References
- **RFC Editor**: https://www.rfc-editor.org/
  - Official protocol specifications
  - Key RFCs: 791 (IP), 793 (TCP), 768 (UDP), 1035 (DNS), 2616 (HTTP/1.1)

- **Internet Engineering Task Force (IETF)**: https://www.ietf.org/
  - Protocol development and standards

### Learning Platforms
- **Cisco Networking Academy**: https://www.netacad.com/
  - Structured networking courses
  - Packet Tracer simulation software

- **Khan Academy - Networking**: https://www.khanacademy.org/computing/computer-science/internet-protocols
  - Beginner-friendly introductions

- **Computer Science Courses**: https://www.freecodecamp.org/news/tag/computer-science/

### Interactive Tools
- **Wireshark**: https://www.wireshark.org/
  - Network protocol analyzer
  - Essential for hands-on learning
  - Tutorials: https://www.wireshark.org/docs/

- **Cisco Packet Tracer**: https://www.netacad.com/courses/packet-tracer
  - Network simulation environment
  - Free with Cisco Networking Academy registration

- **GNS3**: https://www.gns3.com/
  - Network emulation platform
  - Supports real OS images

- **Mininet**: http://mininet.org/
  - SDN network emulator
  - Python API for network programmability
