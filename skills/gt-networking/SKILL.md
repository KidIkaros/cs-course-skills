# Georgia Tech CS 6250 - Computer Networking

Comprehensive coverage of internet infrastructure and network protocols from Georgia Tech's OMSCS program.

## When to Use

- Learning network protocols and their functions
- Understanding TCP/IP stack and layered architecture
- Studying routing algorithms and protocols (BGP, OSPF)
- Exploring DNS resolution and hierarchy
- Analyzing HTTP/HTTPS and web protocols
- Investigating network security threats and defenses
- Examining wireless networking standards

## Core Topics

### 1. Network Fundamentals
- OSI and TCP/IP layered models
- Packet switching vs circuit switching
- Network performance metrics (bandwidth, latency, throughput)
- Multiplexing and encapsulation

### 2. Link Layer & MAC
- Ethernet and IEEE 802.3
- MAC addresses and frame structure
- ARP (Address Resolution Protocol)
- Switches and VLANs
- Spanning Tree Protocol (STP)

### 3. Network Layer & IP
- IPv4 addressing and subnetting
- CIDR and route aggregation
- NAT (Network Address Translation)
- IPv6 fundamentals
- ICMP and ping diagnostics

### 4. Routing
- Forwarding vs routing distinction
- Link-state routing (OSPF)
- Distance-vector routing (RIP)
- Path-vector routing (BGP)
- Software-Defined Networking (SDN)

### 5. Transport Layer
- TCP reliable delivery mechanisms
- TCP flow control (sliding window)
- TCP congestion control (slow start, AIMD)
- UDP characteristics and use cases
- TCP connection management (3-way handshake)

### 6. Application Layer
- DNS hierarchy and resolution
- HTTP/1.1, HTTP/2, HTTP/3
- SMTP, POP3, IMAP for email
- DHCP for address allocation

### 7. Network Security
- Symmetric and asymmetric cryptography
- TLS/SSL handshake and certificates
- IPsec and VPNs
- Firewalls and intrusion detection
- Common attacks (DDoS, spoofing, MITM)

### 8. Wireless & Mobile Networks
- IEEE 802.11 (Wi-Fi) standards
- CSMA/CA and wireless MAC protocols
- Cellular network generations (4G LTE, 5G)
- Mobile IP and handoff

## Study Approach

1. **Layer-by-layer**: Master each OSI layer before moving up
2. **Protocols first**: Understand protocol headers and state machines
3. **Hands-on**: Use Wireshark for packet capture analysis
4. **Practice problems**: Work through subnetting and routing calculations

## Prerequisites

- Basic programming knowledge
- Familiarity with binary/hexadecimal number systems
- Understanding of client-server architecture
