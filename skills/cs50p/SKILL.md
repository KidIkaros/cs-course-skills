# CS50P: Introduction to Programming with Python

Harvard University's free introduction to programming using Python. Covers fundamentals through advanced topics over 10 weeks.

## Course Overview

CS50P is designed for students with no prior programming experience. The course teaches computational thinking and problem-solving through Python programming.

## Weekly Topics

### Week 0: Functions, Variables
- Installing Python and VS Code
- Writing your first program
- Functions and arguments
- Variables and types
- Integer arithmetic
- Type conversion
- Conditionals (if/elif/else)

### Week 1: Conditionals
- Boolean expressions
- Logical operators (and, or, not)
- Comparison operators
- Nested conditionals
- Ternary operators

### Week 2: Loops
- `while` loops
- `for` loops
- `range()` function
- Loop control (break, continue)
- Nested loops

### Week 3: Exceptions
- `try`/`except` blocks
- Multiple except clauses
- Raising exceptions
- Common exception types
- Clean error handling

### Week 4: Libraries
- Importing modules
- `from...import` syntax
- Common standard library modules
- `math`, `random`, `statistics`
- Third-party packages

### Week 5: Unit Tests
- `pytest` framework
- Writing test functions
- Assertions
- Running tests
- Test-driven development

### Week 6: File I/O
- Reading files
- Writing files
- Context managers (`with` statement)
- CSV processing
- JSON handling

### Week 7: Regular Expressions
- `re` module
- Pattern matching
- Quantifiers and anchors
- Groups and capturing
- Common patterns

### Week 8: Object-Oriented Programming
- Classes and objects
- Attributes and methods
- `__init__` constructor
- `self` parameter
- Inheritance
- Polymorphism

### Week 9: Advanced Topics
- Decorators
- Generators
- Lambda functions
- List comprehensions
- Dictionary comprehensions
