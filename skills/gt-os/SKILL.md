# Georgia Tech CS 6200 - Introduction to Operating Systems

## Course Overview

Georgia Tech's CS 6200 is an intermediate-advanced level course covering fundamental operating system concepts. Free on Udacity, it provides deep understanding of how modern operating systems manage processes, memory, and resources.

## When to Use This Skill

- Learning process creation, scheduling, and lifecycle management
- Understanding threads, concurrency, and parallelism
- Implementing synchronization primitives (mutexes, semaphores, monitors)
- Working with virtual memory, paging, and page replacement algorithms
- Designing file systems and understanding I/O management
- Debugging race conditions, deadlocks, and concurrency bugs
- Systems programming in C/C++ with POSIX APIs

## Core Concepts

1. **Process Management**: Creation (fork/exec), scheduling algorithms, inter-process communication
2. **Threading**: User-level vs kernel threads, pthreads, thread lifecycle
3. **Synchronization**: Critical sections, mutexes, semaphores, monitors, condition variables
4. **Deadlock**: Detection, prevention, avoidance, and recovery strategies
5. **Memory Management**: Allocation strategies, fragmentation, segmentation
6. **Virtual Memory**: Paging, page tables, TLBs, page replacement (LRU, Clock, LFU)
7. **File Systems**: Inodes, directory structures, journaling, RAID levels
8. **I/O Systems**: Device drivers, buffering, caching, disk scheduling
