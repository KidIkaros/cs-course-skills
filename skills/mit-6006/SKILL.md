# MIT 6.006 — Introduction to Algorithms

**Instructors:** Erik Demaine, Jason Ku, Justin Solomon (Spring 2020)
**Level:** Intermediate
**Format:** MIT OpenCourseWare — lecture videos, problem sets, exams

## When to Use This Skill

- Learning algorithm design and analysis
- Studying computational complexity (Big-O, NP-completeness)
- Implementing sorting algorithms (merge sort, quicksort, heapsort, counting sort, radix sort)
- Working with graph algorithms (BFS, DFS, Dijkstra's, Bellman-Ford)
- Solving dynamic programming problems
- Preparing for coding interviews on algorithms

## Course Structure

### Unit 1: Introduction & Computational Complexity
- Lecture 1: Algorithms and Computation
- Lecture 2: Computational Complexity: Models of Computation
- Lecture 3: Sorting I (Insertion Sort, Merge Sort)

### Unit 2: Sorting
- Lecture 4: Sorting II (Heapsort)
- Lecture 5: Sorting III (Lower Bounds, Linear-Time Sorting)
- Lecture 6: Sorting IV (Counting Sort, Radix Sort)

### Unit 3: Hashing
- Lecture 7: Hashing I (Chaining, Hash Functions)
- Lecture 8: Hashing II (Open Addressing, Universal Hashing)

### Unit 4: Graphs
- Lecture 9: Graphs I (Introduction, BFS)
- Lecture 10: Graphs II (DFS)
- Lecture 11: Graphs III (Dijkstra's Algorithm)
- Lecture 12: Graphs IV (Bellman-Ford, DAG Shortest Paths)

### Unit 5: Dynamic Programming
- Lecture 13: Dynamic Programming I (Fibonacci, Rod Cutting)
- Lecture 14: Dynamic Programming II (Parenthesization, Edit Distance)

### Unit 6: Advanced Topics
- Lecture 15: NP-Completeness I (P vs NP, Reductions)
- Lecture 16: NP-Completeness II (SAT, 3-SAT, Clique)
- Lecture 17: Algorithms for DNA Sequence Matching

## Key Resources

- **Lecture Videos:** [MIT OCW Spring 2020](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)
- **Problem Sets:** 6 problem sets with solutions on OCW
- **Exams:** 2 quizzes + final exam with solutions

## Study Recommendations

1. Watch lectures sequentially — each builds on the previous
2. Implement every algorithm discussed in lecture
3. Complete all problem sets before checking solutions
4. Focus on understanding *why* algorithms work, not just *how*
5. Practice analyzing time/space complexity of your implementations
