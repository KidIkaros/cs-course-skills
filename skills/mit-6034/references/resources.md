## MIT OpenCourseWare Tips

1. **Watch lectures in order** — concepts build on each other
2. **Do problem sets before watching solutions** — struggle is learning
3. **Use textbook as reference** — Winston's lectures complement Russell & Norvig
4. **Re-implement algorithms from scratch** — don't just read code
5. **Test with small examples first** — trace by hand before coding
