# CS50x - Introduction to Computer Science

Harvard University's introduction to computer science and programming for students with no prior programming experience. Taught by David J. Malan, this course covers computational thinking, abstraction, algorithms, data structures, and web development.

## Learning Objectives

- Think algorithmically and solve problems efficiently
- Understand core programming concepts in C, Python, and SQL
- Learn about algorithms, data structures, memory management
- Build web applications with HTML, CSS, JavaScript, and Flask
- Apply computational thinking to real-world problems

## Prerequisites

- None. This course is designed for students with no prior programming experience.
- A laptop (Mac, PC, or Linux) with administrative privileges to install software

## Course Format

- **Duration**: 11 weeks (self-paced, can be completed over weeks or months)
- **Content**: Video lectures, short videos, notes, problem sets, final project
- **Cost**: Free to take; certificate available for a fee
- **Platform**: edX

## Weekly Topics

### Week 0 - Scratch
- Computational thinking
- Binary and data representation
- Algorithms and pseudocode
- Scratch visual programming
- **Key concept**: Abstraction, decomposition, patterns

### Week 1 - C
- Source code vs. machine code
- Compilers and compilation
- Data types, variables, operators
- Conditionals (if/else), loops
- Functions and scope
- **Key concept**: Memory management, types

### Week 2 - Arrays
- Arrays and strings
- Command-line arguments
- Cryptography basics
- **Key concept**: Indexed data, linear search, bubble sort

### Week 3 - Algorithms
- Searching (binary search)
- Sorting (selection sort, merge sort)
- Recursion
- Asymptotic notation (Big O)
- **Key concept**: Algorithmic efficiency, divide and conquer

### Week 4 - Memory
- Pointers and memory addresses
- String manipulation
- Dynamic memory allocation (malloc, free)
- File I/O
- **Key concept**: Pointer arithmetic, memory layout

### Week 5 - Data Structures
- Structs and custom types
- Linked lists
- Hash tables
- Tries
- Stacks and queues
- **Key concept**: Tradeoffs between data structures

### Week 6 - Python
- Python syntax vs. C
- Functions, conditions, loops
- Libraries and modules
- Regular expressions
- File I/O
- **Key concept**: High-level language advantages

### Week 7 - SQL
- Relational databases
- CRUD operations (SELECT, INSERT, UPDATE, DELETE)
- SQL injection and protection
- Indexes and performance
- **Key concept**: Data modeling, normalization

### Week 8 - HTML, CSS, JavaScript
- HTML structure and semantics
- CSS styling and responsiveness
- JavaScript and DOM manipulation
- Developer tools
- **Key concept**: Front-end web development

### Week 9 - Flask
- HTTP methods and routes
- Templates and Jinja2
- Forms and user input
- Sessions and cookies
- APIs and JSON
- **Key concept**: MVC pattern, web frameworks

### Week 10 - Cybersecurity
- Passwords and hashing
- Two-factor authentication
- Encryption
- SQL injection prevention
- **Key concept**: Security fundamentals

### Week 11 - AI
- Image generation
- Large language models
- Prompt engineering
- Ethics of AI
- **Key concept**: Machine learning basics

## Problem Sets

Each week includes a problem set with auto-graded and/or manual-graded components:
- Problem Set 0: Scratch project
- Problem Set 1: C (Mario, credit, plurality runoff)
- Problem Set 2: Arrays (readability, substitution, caesar)
- Problem Set 3: Algorithms (sort, plurality/runoff, tideman)
- Problem Set 4: Memory (filter, recover)
- Problem Set 5: Data Structures (speller)
- Problem Set 6: Python (hello, mario, credit, DNA)
- Problem Set 7: SQL (songs, movies, money)
- Problem Set 8: Web (homepage, trivia)
- Problem Set 9: Flask (finance)
- Final Project: Student's choice

## Tips for Success

1. Watch lectures at 1.5x or 2x speed to save time
2. Do the walkthroughs alongside lectures
3. Start problem sets early; they take more time than expected
4. Use the CS50 IDE (VS Code for CS50) for all assignments
5. Join the CS50 community (Discord, Reddit) for help
6. Don't just copy solutions; understand the "why"
