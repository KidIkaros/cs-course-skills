# CS 4820/5820 — Topic Breakdown

## Module 1: Foundations
- Algorithm analysis: Big-O, Big-Theta, Big-Omega
- Recurrences and the Master Theorem
- Asymptotic notation and growth of functions
- Proof techniques: induction, contradiction, loop invariants

## Module 2: Greedy Algorithms
- Greedy choice property and optimal substructure
- Exchange argument proofs
- Activity selection / interval scheduling
- Huffman coding and prefix-free codes
- Minimum spanning tree (Kruskal's, Prim's)
- Matroid theory introduction

## Module 3: Divide and Conquer
- Recurrence relations for D&C algorithms
- Merge sort and close variants
- Closest pair of points
- Strassen's matrix multiplication
- Fast Fourier Transform (FFT)
- Selection in linear time (median-of-medians)

## Module 4: Dynamic Programming
- Optimal substructure and overlapping subproblems
- Memoization vs. tabulation
- Longest Common Subsequence (LCS)
- Edit distance (Levenshtein)
- Knapsack (0/1 and unbounded)
- Matrix chain multiplication
- All-pairs shortest paths (Floyd-Warshall)
- Single-source shortest paths (Bellman-Ford)
- Sequence alignment and Viterbi decoding

## Module 5: Network Flow
- Flow networks, max-flow min-cut theorem
- Ford-Fulkerson method
- Edmonds-Karp algorithm
- Applications: bipartite matching, edge-disjoint paths
- Applications: project selection, baseball elimination
- Min-cost max-flow introduction

## Module 6: NP-Completeness
- Complexity classes P, NP, NP-hard, NP-complete
- Polynomial-time reductions
- Cook-Levin theorem (SAT is NP-complete)
- Key NP-complete problems: 3-SAT, Clique, Vertex Cover, Hamiltonian Cycle, TSP, Subset Sum, Graph Coloring
- Coping with NP-hardness: restricted inputs, parameterized complexity

## Module 7: Approximation Algorithms
- Approximation ratios and performance guarantees
- Vertex Cover: 2-approximation
- Set Cover: O(log n)-approximation
- Metric TSP: 2-approximation (MST doubling) and 3/2-approximation (Christofides)
- Knapsack: PTAS via rounding
- Linear programming relaxation and rounding

## Module 8: Local Search and Randomized Algorithms
- Hill climbing and local optima
- Simulated annealing
- Randomized quicksort analysis
- Randomized selection
- Hashing: universal and perfect
- Coupon collector, birthday paradox
- Randomized min-cut (Karger's algorithm)

## Module 9: Advanced Topics (5820 only)
- Parameterized complexity and FPT
- Streaming algorithms and sketching
- Online algorithms and competitive analysis
- Computational geometry: convex hull, Voronoi diagrams
- Algebraic algorithms beyond FFT
