## Textbooks

### Primary
- **"Introduction to Algorithms" (CLRS)** - Cormen, Leiserson, Rivest, Stein
  - Comprehensive reference for all topics
  - Chapter by chapter alignment with CS 161

### Supplementary
- **"Algorithm Design"** - Kleinberg & Tardos
  - Excellent for greedy algorithms and network flow
  - Clear presentation of NP-completeness

- **"Algorithms"** - Dasgupta, Papadimitriou, Vazirani
  - Free online: http://www.cs.berkeley.edu/~vazirani/algorithms.pdf
  - Intuitive explanations, great for building intuition

- **"The Algorithm Design Manual"** - Skiena
  - Practical perspective and implementation focus

- **"Algorithms Illuminated"** - Tim Roughgarden
  - Companion to Coursera specialization
  - Four volumes covering core topics

## Practice Problems by Topic

### Sorting & Selection
- Merge sort implementation and counting inversions
- Quicksort: randomized, median-of-three, 3-way partition
- Selection algorithms: quickselect, median of medians

### Dynamic Programming
- LeetCode: Climbing Stairs, Coin Change, Longest Common Subsequence
- Edit Distance, Knapsack problems
- DP on trees and intervals

### Graph Algorithms
- BFS/DFS traversal and applications
- Topological sort problems
- MST: Kruskal's and Prim's implementations
- Shortest paths: Dijkstra's, Bellman-Ford

### Hashing
- Hash function design
- Collision resolution strategies
- Bloom filter analysis

## Study Tips

1. **Implement everything** - Code every algorithm from scratch at least once
2. **Prove correctness** - Practice exchange arguments for greedy, induction for DP
3. **Trace algorithms** - Run through examples by hand before coding
4. **Time yourself** - Practice solving problems under time pressure
5. **Form study groups** - Explain concepts to others to solidify understanding
6. **Review past exams** - Stanford posts previous CS 161 exams on the course website
