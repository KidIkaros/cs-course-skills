# CS 161 - Syllabus & Topic Breakdown

**Stanford University | Winter 2026**
**Instructors:** Moses Charikar, Ellen Vitercik

---

## Week 1: Introduction & Complexity Analysis

- Course overview, administrative details
- Computational problems, algorithms, correctness proofs
- Asymptotic notation: O, Ω, Θ
- Growth of functions, basic asymptotic analysis
- Time and space complexity

**Key Questions:**
- What makes some problems harder than others?
- How do we formally compare algorithm efficiency?

---

## Week 2: Divide and Conquer

- Divide-and-conquer paradigm
- Master theorem and recursion trees
- Merge sort revisited
- Counting inversions
- Closest pair of points

**Algorithms:** Merge sort, counting inversions, closest pair

---

## Week 3: Dynamic Programming I

- Optimal substructure property
- Overlapping subproblems
- Memoization vs. tabulation
- Longest Common Subsequence (LCS)
- Edit distance

**Algorithms:** LCS, edit distance

---

## Week 4: Dynamic Programming II

- Matrix chain multiplication
- Knapsack problem (0/1 and unbounded)
- Shortest paths (Floyd-Warshall)
- DP on trees

**Algorithms:** Matrix chain, knapsack, Floyd-Warshall

---

## Week 5: Greedy Algorithms

- Greedy choice property
- Exchange arguments for correctness proofs
- Activity selection / interval scheduling
- Huffman coding
- Matroids and greedy optimality

**Algorithms:** Activity selection, Huffman, fractional knapsack

---

## Week 6: Graph Algorithms I

- Graph representations (adjacency list, matrix)
- BFS: shortest paths in unweighted graphs
- DFS: discovery/finish times, edge classification
- Topological sort (DAGs)
- Strongly connected components (Kosaraju's/Tarjan's)

**Algorithms:** BFS, DFS, topological sort, SCC

---

## Week 7: Midterm & Minimum Spanning Trees

- Midterm exam
- Cut property and cycle property
- Kruskal's algorithm (Union-Find)
- Prim's algorithm
- Union-Find data structure (path compression, union by rank)

**Algorithms:** Kruskal's, Prim's, Union-Find

---

## Week 8: Shortest Paths

- Single-source shortest paths
- Dijkstra's algorithm (priority queue implementation)
- Bellman-Ford algorithm (negative weights)
- DAG shortest paths
- Comparison of shortest path algorithms

**Algorithms:** Dijkstra's, Bellman-Ford, DAG shortest paths

---

## Week 9: Amortized Analysis & Advanced Data Structures

- Amortized analysis: aggregate, accounting, potential methods
- Dynamic arrays / amortized O(1) insertion
- Binary search trees: rotations, balanced BSTs
- Red-black trees / AVL trees (overview)
- Heaps and priority queues

**Data Structures:** BSTs, heaps, dynamic arrays

---

## Week 10: Hashing & Randomized Algorithms

- Hash tables: chaining, open addressing
- Universal hashing, perfect hashing
- Load factor and expected performance
- Randomized algorithms: randomized quicksort, skip lists
- Bloom filters

**Algorithms:** Hashing, randomized quicksort, Bloom filters

---

## Week 11: Network Flow (if time permits)

- Max-flow min-cut theorem
- Ford-Fulkerson method
- Edmonds-Karp algorithm
- Applications: bipartite matching

**Algorithms:** Ford-Fulkerson, Edmonds-Karp

---

## Final Exam

Comprehensive final covering all topics.
