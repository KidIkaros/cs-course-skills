# Stanford CS 229 — Machine Learning

Stanford's flagship machine learning course taught by Andrew Ng. Covers the mathematical foundations and practical algorithms of ML with rigorous derivations.

## Prerequisites

- **Linear Algebra**: Vector spaces, matrix decomposition, eigenvalues/eigenvectors
- **Probability & Statistics**: Distributions, Bayes' rule, MLE/MAP, expectation, variance
- **Calculus**: Multivariate calculus, gradients, Hessians, optimization

## Course Topics

### Part I: Supervised Learning
- Linear regression, least squares, gradient descent
- Logistic regression, generative models, GDA
- Generalized linear models, exponential family
- Support vector machines, max-margin classifiers
- Kernels: polynomial, Gaussian RBF, Mercer's theorem

### Part II: Unsupervised Learning
- K-means clustering
- Hierarchical clustering
- Expectation-Maximization (EM) algorithm
- Principal Component Analysis (PCA)
- Factor analysis

### Part III: Special Topics
- Hidden Markov Models (HMMs)
- Reinforcement learning (MDPs, value iteration, policy iteration)
- Bandit algorithms
- Reinforcement learning and control
