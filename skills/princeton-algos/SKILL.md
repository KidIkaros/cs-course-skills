# Princeton COS 226 - Algorithms and Data Structures

Princeton University's Algorithms and Data Structures course taught by Robert Sedgewick and Kevin Wayne. Free course website with complete Java implementations for every algorithm discussed.

## When to Use

- Learning or reviewing fundamental algorithms and data structures
- Implementing sorting, searching, graph, or string algorithms in Java
- Preparing for technical interviews covering algorithm topics
- Understanding algorithm design paradigms (divide-and-conquer, greedy, dynamic programming)
- Needing production-quality Java implementations of classic algorithms

## Course Structure

### Part I: Fundamentals
- **Union-Find** - Dynamic connectivity, quick-union, weighted quick-union
- **Analysis of Algorithms** - Scientific approach, mathematical models
- **Stacks and Queues** - ADTs, resizing arrays, linked lists
- **Elementary Sorts** - Selection sort, insertion sort, shellsort, mergesort, quicksort
- **Priority Queues** - Binary heaps, heapsort, index min-priority queues

### Part II: Sorting
- **Mergesort** - Top-down, bottom-up, optimization
- **Quicksort** - Partitioning, selection, 3-way partitioning
- **Elementary Symbol Tables** - BSTs, ordered operations

### Part III: Searching
- **Binary Search Trees** - Search, insert, delete, ordered operations
- **Balanced Search Trees** - Red-black BSTs, 2-3 trees, B-trees
- **Hash Tables** - Hash functions, separate chaining, linear probing

### Part IV: Graphs
- **Undirected Graphs** - DFS, BFS, connected components, cycles
- **Directed Graphs** - DFS, BFS, topological sort, strongly connected components
- **Minimum Spanning Trees** - Kruskal's algorithm, Prim's algorithm
- **Shortest Paths** - Dijkstra's algorithm, Bellman-Ford algorithm

### Part V: Strings
- **String Sorts** - LSD radix sort, MSD radix sort, quicksort for strings
- **Tries** - R-way tries, ternary search tries
- **Substring Search** - KMP, Boyer-Moore, Rabin-Karp
- **Regular Expressions** - NFA construction and simulation
- **Data Compression** - Huffman, LZW, arithmetic coding

### Part VI: Advanced
- **Substring Search** - Finite automata, Knuth-Morris-Pratt
- **Network Flow** - Ford-Fulkerson, maxflow-mincut
- **Linear Programming** - Simplex algorithm

## Key Resources

All implementations are in Java. Code follows clean, well-documented conventions suitable for learning. The library (algs4.jar) provides I/O utilities and visualization tools.
