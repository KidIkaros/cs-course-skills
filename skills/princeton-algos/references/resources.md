## Textbook

**Algorithms** (4th Edition)
- Authors: Robert Sedgewick, Kevin Wayne
- Publisher: Addison-Wesley Professional (2011)
- ISBN: 978-0321573513
- Free online access: https://algs4.cs.princeton.edu/home/
- Covers 200 algorithms with 400+ Java implementations

## Java Implementation Library

The algs4.jar library provides:
- All data structures (Stack, Queue, BST, RedBlackBST, Heap, Trie, etc.)
- All algorithms (sorting, searching, graph, string processing)
- I/O utilities (In, Out, StdIn, StdOut, StdDraw, StdRandom, StdStats)
- Visualization tools for interactive learning
- Download: https://algs4.cs.princeton.edu/code/
