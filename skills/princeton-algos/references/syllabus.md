# COS 226 - Algorithms and Data Structures

**University**: Princeton University
**Instructors**: Robert Sedgewick, Kevin Wayne
**Level**: Intermediate
**Textbook**: *Algorithms* (4th Edition) by Robert Sedgewick and Kevin Wayne
**Course URL**: https://algs4.cs.princeton.edu/

## Course Description

An introduction to essential information about algorithms and data structures, with emphasis on scientific applications. The course teaches a scientific approach to algorithm design and analysis, using empirical results to validate mathematical models and verify correctness.

## Part I: Fundamentals

| Topic | Key Concepts | Chapter |
|--------|-------------|---------|
| Union-Find | Dynamic connectivity, quick-find, quick-union, weighted quick-union, path compression | 1.5 |
| Analysis of Algorithms | Scientific approach, mathematical modeling, order-of-growth classifications | 1.4 |
| Stacks and Queues | ADT design, linked lists, resizing arrays, iterators | 1.3 |
| Elementary Sorts | Selection, insertion, shellsort, mergesort, quicksort comparison | 2.1, 2.2 |
| Priority Queues | Binary heap, heapsort, index min-priority queue | 2.4 |

## Part II: Sorting

| Topic | Key Concepts | Chapter |
|--------|-------------|---------|
| Mergesort | Top-down, bottom-up, stability, optimization | 2.2 |
| Quicksort | Partitioning, select, 3-way partitioning, duplicates | 2.3 |
| Elementary Symbol Tables | BST, ordered operations, sequential search | 3.1 |

## Part III: Searching

| Topic | Key Concepts | Chapter |
|--------|-------------|---------|
| Binary Search Trees | Search, insert, delete, range operations | 3.2 |
| Balanced Search Trees | 2-3 trees, red-black BSTs, B-trees | 3.3, 3.5 |
| Hash Tables | Hash functions, separate chaining, linear probing | 3.4 |

## Part IV: Graphs

| Topic | Key Concepts | Chapter |
|--------|-------------|---------|
| Undirected Graphs | DFS, BFS, connected components, cycles, bipartiteness | 4.1 |
| Directed Graphs | DFS, BFS, topological sort, SCCs, web | 4.2 |
| Minimum Spanning Trees | Kruskal's, Prim's, edge-weighted graphs | 4.3 |
| Shortest Paths | Dijkstra's, Bellman-Ford, negative weights, DAGs | 4.4 |

## Part V: Strings

| Topic | Key Concepts | Chapter |
|--------|-------------|---------|
| String Sorts | LSD radix, MSD radix, 3-way quicksort | 5.1 |
| Tries | R-way tries, TSTs, char-based operations | 5.2 |
| Substring Search | KMP, Boyer-Moore, Rabin-Karp | 5.3 |
| Regular Expressions | NFA construction and simulation | 5.4 |
| Data Compression | Huffman, LZW, arithmetic coding | 5.5 |

## Part VI: Advanced Topics

| Topic | Key Concepts | Chapter |
|--------|-------------|---------|
