# CS 221 Problem Sets & Projects

## Problem Sets

### Problem Set 1: Search
- Implement BFS, DFS, and A* search
- Design heuristics for 8-puzzle and gridworld
- Analyze optimality and completeness
- UCS vs A* comparison on varying heuristic quality

**Skills practiced**: algorithm design, asymptotic analysis, heuristic reasoning

---

### Problem Set 2: Adversarial Search
- Implement minimax with alpha-beta pruning
- Build evaluation function for checkers or chess
- Implement expectimax for stochastic games
- Compare minimax vs expectimax performance

**Skills practiced**: game theory, tree search, evaluation function design

---

### Problem Set 3: Constraint Satisfaction
- Build a CSP solver for Sudoku
- Implement arc consistency (AC-3)
- Compare backtracking with MRV + LCV heuristics
- Apply local search (min-conflicts) to N-queens

**Skills practiced**: constraint reasoning, search optimization, decomposition

---

### Problem Set 4: Markov Decision Processes
- Implement value iteration on gridworld MDPs
- Implement policy iteration
- Compare convergence speed of VI vs PI
- Solve MDP with large state space using function approximation

**Skills practiced**: dynamic programming, Bellman equations, RL basics

---

### Problem Set 5: Machine Learning
- Implement linear regression with gradient descent
- Build logistic regression classifier
- Implement neural network with backpropagation
- Apply SVM with kernel trick
- Evaluate with cross-validation, precision/recall

**Skills practiced**: optimization, gradient methods, model evaluation

---

### Problem Set 6: Probabilistic Models
- Build Bayesian network and perform inference
- Implement variable elimination
- Apply forward-backward algorithm to HMM
- Implement particle filter for robot localization

**Skills practiced**: probabilistic reasoning, sampling methods, dynamic systems

---

## Projects

### Project 1: Search Application
**Pick one domain**:
- Solve a real-world routing problem (e.g., flight itinerary optimization)
- Build a puzzle solver (Sudoku, KenKen, or sliding tiles)
- Implement game AI (Othello/Reversi with minimax + alpha-beta)

**Deliverables**: Working implementation, heuristic analysis, performance evaluation

---

### Project 2: Machine Learning Application
**Pick one domain**:
- Image classification with neural networks (CIFAR-10)
- Spam classifier with feature engineering
- Sentiment analysis on movie reviews
- Predicting student performance from course data

**Deliverables**: Model comparison, ablation studies, error analysis

---

### Project 3: Reinforcement Learning Application
**Pick one domain**:
- Train agent to play a game (Pac-Man, Flappy Bird, or custom)
- Robot navigation with Q-learning
- Resource allocation optimization with MDP
- Simulated trading strategy with RL

**Deliverables**: Learning curves, policy visualization, parameter sensitivity analysis

## Exam Preparation

### Midterm Topics
1. Search algorithms and heuristics
2. Adversarial search (minimax, alpha-beta)
3. Constraint satisfaction problems
4. Markov decision processes (value/policy iteration)

### Final Exam Topics
1. Machine learning (linear models, neural networks, SVMs)
2. Probabilistic graphical models
3. Hidden Markov models and inference
4. Logic and planning
5. Advanced topics (NLP, vision, robotics)

### Study Strategies
- **Work through past exams**: available on course website
- **Implement algorithms by hand**: trace through small examples
- **Focus on intuition**: understand *why* algorithms work, not just *how*
- **Connect concepts**: MDPs relate to search; ML relates to probability
- **Practice proofs**: some questions require formal reasoning about properties

## Tips for Success

1. **Start early** — problem sets and projects have long lead times
2. **Attend sections** — TAs cover material not in lectures
3. **Form study groups** — peer discussion accelerates learning
4. **Office hours** — use them for conceptual confusion, not debugging
5. **Read the textbook** — lectures are overview; textbook is reference
6. **Implement before theorizing** — coding reveals gaps in understanding
