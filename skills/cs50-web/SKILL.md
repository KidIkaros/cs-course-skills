# CS50 Web - Web Programming with Python and JavaScript

Harvard University's OpenCourseWare course on modern web development.

## Overview

CS50 Web covers the fundamentals of web development with Python and JavaScript, including Django, React, SQL, APIs, Git, and deployment. This is an intermediate course that assumes completion of CS50x or equivalent programming experience.

## Prerequisites

- CS50x (Introduction to Computer Science) or equivalent
- Basic Python and JavaScript proficiency
- Command line familiarity

## Course Structure (9 Weeks)

| Week | Topic | Key Project |
|------|-------|-------------|
| 0 | HTML, CSS, JavaScript | Network |
| 1 | Git, Python, Django | Auctions |
| 2 | SQL, Models, Migrations | Commerce |
| 3 | Django Relationships | Mail |
| 4 | JavaScript Fundamentals | Wiki |
| 5 | React | Calculator |
| 6 | React (continued) | Inbox |
| 7 | Testing, CI/CD | Pizza |
| 8 | Security, Scalability | Network 2 |

## How to Use This Skill

Use this skill when:

- Building Django or Flask web applications
- Creating React frontends
- Designing SQL database schemas
- Implementing REST APIs
- Working with Git workflows
- Setting up CI/CD pipelines
- Deploying web applications
- Learning modern web development patterns

## Key Commands

```bash
# Django
django-admin startproject <project>
python manage.py runserver
python manage.py makemigrations

# React

# Git
git init

# Testing
python manage.py test
```
