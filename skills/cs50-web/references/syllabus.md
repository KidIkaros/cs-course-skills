# CS50 Web — Weekly Syllabus Breakdown

## Week 0: HTML, CSS, JavaScript

**Topics:**
- HTML5 semantic elements, forms, and validation
- CSS selectors, specificity, flexbox, and grid
- JavaScript basics: variables, functions, DOM manipulation
- Event handling and interactivity
- Responsive design principles

**Project: Network**
- Build a Twitter-like social network frontend
- Multi-page application with HTML/CSS
- Dynamic content updates via JavaScript

**Key Skills:**
- Semantic HTML structure
- CSS layout techniques (flexbox, grid)
- Vanilla JavaScript DOM manipulation
- Form validation (client-side)

---

## Week 1: Git, Python, Django

**Topics:**
- Git version control: init, add, commit, branch, merge
- GitHub workflows: push, pull, pull requests
- Python refresher: data structures, functions, classes, decorators
- Django project structure and MVC pattern
- URL routing, views, templates
- Template inheritance and context variables

**Project: Auctions**
- Full-stack auction site with Django
- User authentication, listing creation, bidding
- Category filtering and search

**Key Skills:**
- Git branching and merging strategies
- Django URL configuration
- Template rendering with context
- Static file management

---

## Week 2: SQL, Models, Migrations

**Topics:**
- Relational database fundamentals
- SQL: SELECT, INSERT, UPDATE, DELETE, JOINs
- Django ORM: models, fields, relationships
- Model relationships: ForeignKey, ManyToMany, OneToOne
- Database migrations with Django
- QuerySets: filtering, ordering, aggregation

**Project: Commerce**
- E-commerce platform with product listings
- Shopping cart, checkout, order history
- Category management and search

**Key Skills:**
- Designing database schemas
- Writing efficient Django queries
- Running and reversing migrations
- Admin interface customization

---

## Week 3: Django Relationships

**Topics:**
- Advanced model relationships
- Class-based views vs function-based views
- Django REST framework basics
- Authentication and authorization
- Sessions and cookies
- Form handling with Django

**Project: Mail**
- Email client with inbox, sent, archived views
- Compose, read, reply to emails
- Mark as read/unread, archive/unarchive

**Key Skills:**
- RESTful API design
- User authentication flows
- Session management
- AJAX with Django views

---

## Week 4: JavaScript Fundamentals

**Topics:**
- Modern ES6+ JavaScript
- Closures, promises, async/await
- Fetch API for network requests
- Error handling patterns
- JavaScript modules and imports
- JSON data handling

**Project: Wiki**
- Markdown-based wiki encyclopedia
- Create, edit, delete entries
- Search functionality
- Markdown-to-HTML conversion

**Key Skills:**
- Asynchronous JavaScript patterns
- API consumption with fetch
- DOM manipulation at scale
- Event delegation

---

## Week 5: React

**Topics:**
- React component architecture
- JSX syntax and expressions
- State management with useState
- Props and component communication
- Event handling in React
- Conditional rendering and lists
- React hooks overview

**Project: Calculator**
- Functional calculator using React
- Component-based UI design
- State management for calculations
- Responsive layout

**Key Skills:**
- Thinking in components
- Managing component state
- Lifting state up
- React DevTools usage

---

## Week 6: React (Advanced)

**Topics:**
- React Router for navigation
- useEffect and side effects
- Context API for global state
- Custom hooks
- Performance optimization (React.memo, useMemo)
- Error boundaries

**Project: Inbox**
- Email client rebuilt in React
- Single-page application architecture
- Client-side routing
- API integration with fetch/axios

**Key Skills:**
- SPA navigation patterns
- Managing complex state
- Performance profiling
- Error handling in React

---

## Week 7: Testing, CI/CD

**Topics:**
- Unit testing with Django TestCase
- JavaScript testing with Jest/React Testing Library
- Integration and end-to-end testing
- Continuous Integration concepts
- GitHub Actions basics
- Test-driven development (TDD)

**Project: Pizza**
- Pizza ordering platform
- Comprehensive test coverage
- CI pipeline setup
- Deployment preparation

**Key Skills:**
- Writing testable code
- Mocking and fixtures
- Test coverage analysis
- CI/CD pipeline configuration

---

## Week 8: Security, Scalability

**Topics:**
- Web security: XSS, CSRF, SQL injection
- Django security features
- HTTPS and SSL/TLS
- Performance optimization
- Caching strategies
- Deployment to production (Heroku, AWS, etc.)
- Web sockets and real-time features

**Project: Network 2**
- Enhanced social network with real-time features
- WebSocket integration
- Security hardening
- Performance optimization

**Key Skills:**
- Security auditing
- Production deployment
- Performance profiling
- Real-time web applications

---

## Final Project

Students choose their own project demonstrating mastery of:
- Frontend and backend development
- Database design and ORM usage
- API design and consumption
- Testing and deployment
- Security best practices
