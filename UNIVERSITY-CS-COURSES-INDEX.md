## Recommended Learning Paths

### Path 1: Complete Beginner → Web Developer
1. `cs50x` - Foundations (C, Python, SQL, web basics)
2. `cs50p` - Python deep dive
3. `cs50-web` - Full-stack web development

### Path 2: Beginner → AI/ML Engineer
1. `cs50x` or `cs50p` - Programming foundations
2. `mit-6006` or `stanford-cs161` - Algorithms
3. `cs50-ai` - AI fundamentals
4. `stanford-cs229` - Mathematical ML

### Path 3: Systems & Compilers
1. `cs50x` - Programming foundations
2. `mit-6006` - Algorithms
3. `cornell-cs4320` - Databases
4. `cornell-cs6120` - Compilers

### Path 4: Theory of Computation
1. `stanford-cs161` - Algorithm design
2. `cornell-cs4820` - Algorithm analysis (theory-heavy)
3. `mit-6006` - Algorithms (implementation)

### Path 5: Full AI Stack
1. `cs50x` + `cs50p` - Programming
2. `mit-6034` - AI foundations
3. `stanford-cs221` - AI principles
4. `stanford-cs229` - ML theory
5. `cs50-ai` - Applied AI projects
